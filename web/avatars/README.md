## 日本語

このツールの説明動画などで使っている、作者が自作した VRM アバター（VRM 1.0）です。**どなたでも自由に使えます。**
Dummy13 VRM Viewer の「VRM を読み込む」で読み込めるほか、VRM に対応したほかのアプリでも使えます。

### 利用条件

VRM ファイルに書き込んである利用条件（[VRM Public License 1.0](https://vrm.dev/licenses/1.0/)）のとおりです。

| 項目 | 条件 |
|---|---|
| アバターとして使う（配信・動画・ゲームなど） | 誰でも OK |
| 商用利用 | OK（個人・法人とも） |
| 改変 | OK |
| 再配布（改変したものを含む） | OK |
| クレジット表記 | 不要 |
| 過度に暴力的な表現・過度に性的な表現・反社会的／憎悪的な用途・政治や宗教の活動での使用 | 不可 |

クレジットの表記は不要ですが、書いてもらえるとうれしいです（例：`アバター：pt`）。
