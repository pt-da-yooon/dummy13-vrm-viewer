Dummy13 点付け

実物の写真に関節の点を付けて、追加学習用のラベル（YOLO 形式）を作ります。今のモデルが下書きした点をドラッグで直してください。 Chrome / Edge 用（フォルダへの保存を使うため）。

（data/real などを選ぶ。写真は中の images/、ラベルは labels/ に保存）
「フォルダを開く」で写真のフォルダを選んでください

関節（クリックで選択）
操作
  • 点をドラッグして関節の中心に合わせる
  • 左右は Dummy13 自身から見た左右（こちらを向いていれば、左は画面の右側）
  • H：選んだ点の状態を切り替え（見えている → 隠れている → 写っていない）。隠れている点も位置は推測して置く
  • ダブルクリック：選んだ点をそこへ移動
  • Tab / Shift+Tab：次 / 前の点を選ぶ
  • ← / →：前 / 次の写真（変更があれば保存）
  • ホイール：拡大縮小　右ドラッグ：移動　F：全体表示
  • 黄緑の枠の角をドラッグすると検出枠を直せる（B：点から作り直す）
  • T：下書きが大きく外れたとき、枠の中に立ちポーズの型を置き直す
  • Enter：保存して次へ　Ctrl+Z：元に戻す
