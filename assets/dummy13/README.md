# Dummy 13 の STL を置く場所 / Where to put the Dummy 13 STL files

**Dummy 13 version 1.0** by soozafone（Lucky 13 Toys）, CC BY 4.0 — https://www.printables.com/model/981111-dummy-13-version-10

## 日本語

STL はこのリポジトリに含めていません。合成データを作るときは、各自でダウンロードしてこのフォルダに置いてください。

1. 上の Printables のページから無料のファイル（ALL MODEL FILES）をダウンロードする。
2. zip を展開し、中の STL と組み立てガイド（PDF）を**このフォルダ（`assets/dummy13/`）の直下**に置く。
   zip の中でフォルダ（Individual parts - frame など）に分かれていたら、中の STL をすべてこのフォルダの直下に移す。
   ファイル名は変えない（例：`frame, chest.stl`、`armor, abdomen.stl`、`hand, open, left.stl`）。
3. `synth/build_rig.py` がここから STL を読み込む。

## English

The STL files are not included. To generate synthetic data, download them yourself and place them here.

1. Download the free files (ALL MODEL FILES) from the Printables page above.
2. Unzip and put the STL files and the assembly guide (PDF) **directly in this folder (`assets/dummy13/`)** without renaming them
   (e.g. `frame, chest.stl`, `armor, abdomen.stl`, `hand, open, left.stl`). If the zip has subfolders (Individual parts - frame, etc.), move all STL files up into this folder.
3. `synth/build_rig.py` reads the STL files from here.
